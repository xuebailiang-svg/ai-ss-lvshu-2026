# Phase B：前端入口与页面范围收敛

## 目标

前端主路径只保留“高德采集 + 人工补充 + 数据检查 + AI 报告”，避免尚未达到稳定产品标准的实验模块干扰使用。

## 主导航

- 选址项目：`/`
- 系统配置：`/settings`

旧路由仍保留兼容跳转，但不再出现在主导航：旧工作台、Agent、历史评估、旧报告、上传中心和调试页面统一跳转到项目列表或对应项目详情。

## 项目流程

项目详情采用六步流程：

1. 确认地址
2. 高德采集
3. 查看与人工补充
4. 数据检查
5. 重要信息确认
6. 生成 AI 报告

主流程不再展示爬虫任务、数据源状态、评分面板、Memory 管理、政府数据或 Agent trace。相关后端代码和数据库表本阶段不删除，以降低回滚和兼容风险。

## 配置范围

系统配置页只提供：

- DeepSeek API Key、API 地址和模型
- 高德 Web Service Key
- 管理员 Token 临时验证
- 保存结果和连接测试反馈

Key 仍由后端加密保存，页面不回显完整值，管理员 Token 不写入浏览器持久存储。

## 验证

- `npm test -- --run`
- `npm run build`

Phase B 完成后停止，不在本阶段删除后端实验模块或修改评分、报告生成逻辑。
