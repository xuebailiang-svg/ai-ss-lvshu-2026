# 决策记录

## 2026-08：产品范围收敛

- 产品收敛为“高德 + 人工补充 + AI 报告”MVP。
- 高德 Web Service 是唯一自动外部数据源。
- 不继续开发爬虫、第三方 Provider、政府数据、热力、Memory、复杂 Agent 和预测能力。
- `site_projects` 是唯一继续演进的项目主链；旧 `site_evaluations` 链路进入只读/待清理状态。
- 页面收敛为项目列表、创建分析、项目详情、系统配置。
- 项目详情固定为地址、高德采集、查看与人工补充、数据检查、AI 提问、报告六步。
- AI 只能读取最终项目数据快照；未知值不可推测。
- 旧模块先隐藏，完成生产备份和引用审计后再删除。

## 技术决策

- 保持 React + FastAPI + PostgreSQL/PostGIS 模块化单体，不拆微服务。
- 生产只通过 Alembic 管理数据库结构。
- Alembic revision ID 长度不得超过默认 32 字符。
- 历史 revision 兼容只允许精确别名替换，不允许自动 stamp 未知数据库。
- 高德值与人工值分层，不相互覆盖。
- 报告版本保存生成时快照，后续项目修改不能悄悄改变旧报告。
- 本地测试可使用 SQLite；生产使用 PostgreSQL/PostGIS。
- 正式 AI 报告只读取 `final_project_snapshot`；旧评分、政府数据、Memory、爬虫、模拟数据和内部原始字段不进入模型输入。
- 报告发布前执行固定八章、结论守卫和数字追溯校验；最多自动重试一次，仍失败则不发布。
