# 周边配套 Provider

`AmapSupportingProvider` 复用现有高德 POI 能力，按餐饮、娱乐和夜经济三组关键词采集数据，并转换为统一的 `FoodBusinessData` 与 `EntertainmentData`。

- 餐饮：餐厅、小吃、快餐、烧烤。
- 娱乐：KTV、酒吧、台球、密室、电影院。
- 夜经济候选：夜市、便利店、超市。

夜经济第一版只做关键词统计。便利店或超市被发现不代表真实夜间营业，营业时间未知时保持为空，不生成营业额或人流量估算。

夜间活跃等级采用透明统计规则：0 条为 `none`，1～2 条为 `low`，3～7 条为 `medium`，8 条及以上为 `high`。
