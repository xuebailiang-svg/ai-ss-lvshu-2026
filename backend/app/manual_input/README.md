# 人工数据补充中心

本模块用于补齐高德 POI 无法提供的经营和成本数据。

当前支持：

- 竞品补充：机器数量、硬件、价格、上座率、销售额、充值金额等。
- 租金补充：月租金、面积、元/㎡、物业费、转让费等。
- 人口补充：周边学校、公寓、住宅数量和目标客群描述。
- 通用备注：继续写入已有 `supplements` 模型。

数据处理原则：

1. 不删除自动采集数据。
2. 人工数据写入对应业务表，并追加到 `manual_inputs` 历史表。
3. 数据优先级为 `manual > crawler > third_party > amap`。
4. 不接入 DeepSeek，不开发爬虫，不修改 Agent、评分模型或报告生成。
