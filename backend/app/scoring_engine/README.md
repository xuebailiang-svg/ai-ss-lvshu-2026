# 电竞馆智能选址评分引擎

本模块是独立评分引擎，只输出结构化评分数据，不生成 AI 报告。

职责：

- `default.yaml`：评分权重和规则配置。
- `rules.py`：读取 YAML 配置。
- `calculator.py`：根据项目 dataset 计算分数、风险、缺失项和置信度。
- `service.py`：读取项目数据、执行评分、保存评分历史。
- `router.py`：提供项目评分 API。

接口：

```http
POST /api/projects/{project_id}/score
```

当前一级指标：

- 人口因素：30 分
- 交通因素：20 分
- 竞争环境：20 分
- 夜间消费环境：20 分，只使用已确认配套数据
- 成本因素：10 分

## 竞争环境透明规则（v1.1）

- 只使用 `confirmed` 竞品计算价格、上座率、机器数量和常见显卡配置。
- `pending_review` 不参与经营均值，每家按 0.5 家计入数量压力。
- `rejected` 不进入评分数据集。
- 有效竞争强度 0～2 家为低、3～5 家为中、超过 5 家为高。
- 价格、上座率和机器数量有真实数据时增加数据依据分；缺失时返回缺失项并降低置信度。
- 平均上座率达到 70% 时，同时标记“市场成熟”和“竞争较强”的风险，不把高上座率简单视为单向加分。

## 夜间消费环境透明规则（v1.2）

- 只使用 `confirmed` 的餐饮、娱乐和夜间商业记录，排除 `pending_review` 与 `rejected`。
- 已确认餐饮达到 20 家加 8 分。
- 人工明确为夜间营业的餐饮达到 5 家加 3 分。
- 已确认娱乐配套达到 5 家加 5 分。
- 人工明确为 24 小时或夜间营业的夜间商业达到 3 家加 4 分。
- 缺少营业时间或夜间营业核实结果时不推测，并降低该维度置信度。

约束：

- 不接 DeepSeek。
- 不生成 AI 报告。
- 不修改 Agent。
- 不开发爬虫。
